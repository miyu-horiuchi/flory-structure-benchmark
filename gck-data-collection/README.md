# GCK compound-labelled datasets

See the [survey report](gck_compound_labelled_datasets.md) for the evidence and join counts. The three checked-in CSVs are the curated PDB entry inventory, allosteric ligand inventory, and per-ligand potency join.

## Regenerate the data

From the repository root, use Python 3 with `requests` installed and network access to RCSB PDB, ChEMBL, and UniChem:

```sh
out="$HOME/gck-output"
python3 gck-data-collection/collect.py --output-dir "$out" candidates
python3 gck-data-collection/collect.py --output-dir "$out" entries
python3 gck-data-collection/collect.py --output-dir "$out" chembl
python3 gck-data-collection/collect.py --output-dir "$out" matches
python3 gck-data-collection/summarize.py --output-dir "$out"
```

Both scripts default to `./gck-output`. The commands above keep the generated files outside the repository. Public database records can change, so a new run may differ from the committed snapshot. The summarizer checks for unclassified ligands and disagreements between exact InChIKey and UniChem mappings rather than silently accepting them.

The full `chembl_gck_activities.csv` (~1.2 MB) is not checked in: it is larger than the repository's existing data exports and can be regenerated by the `chembl` stage. Raw JSON snapshots are intermediate files and are not checked in either.
