# Human glucokinase activators: potency × binding kinetics

**Snapshot: November 23, 2026. 22 experimentally tested samples join: 17 Borzilleri baseline + 5 new.** The five are LY2121260/SGN71, MWI121, S-44520, racemic S-49513 and racemic S-49164. All five add stopped-flow binding kinetics; **no new SPR-rate compound** was verified. Four use an allowed affinity label (Kd); only MWI121 adds a verified concentration–response EC50 (45 nM at 6.5 mM glucose). If requiring EC50 rather than accepting affinity as potency, the verified join is **18 samples (one new)**. Two of the five new rows are racemates; they are neither resolved single molecules nor four new measured enantiomers. No model was trained.

## Files and reproduction

- [Joined](data/gck_kinetics_joined.csv): one preferred observation per tested sample, with assay conditions and a structure-status field. Borzilleri keeps SPR; LY2121260 uses the clearly specified 100 mM glucose, no AMP-PNP Antoine condition. Do not treat rates from these different target states and methods as interchangeable.
- [Kinetics observations](data/gck_kinetics_observations.csv): 28 observations, including additional Antoine/Mollica measurements of already joined samples.
- [Potency](data/gck_potency_all.csv): 2,953 source observations, **not** unique compounds or homogeneous activator data. Includes non-activator binding/inhibition context and database duplicates, with source-specific identifiers and relations preserved. It covers all populated accepted-type database records and the curated values listed below; it is not an exhaustive transcription of the patent/literature hits. Glucose S0.5/S50, Km, kcat, activation maxima, percent effects and unpopulated standard values were not treated as compound-concentration potency.
- [Candidates](data/gck_kinetics_candidates.csv): reviewed partial kinetic leads that did not pass the join.

The committed CSVs are the November 2026 snapshot. Raw database responses are not committed: regenerate `data/chembl_gck_activities.json`, `data/chembl_source_compounds.json` and `data/bindingdb_gck_activities.csv` before rebuilding. With a clean checkout the build exits with the commands to fetch missing inputs. Run from the repository root:

```sh
cd gck-kinetics/scripts
python fetch_databases.py chembl
python fetch_databases.py compounds
python fetch_databases.py bindingdb
python build_tables.py
python validate_tables.py
```

Python 3.10+ and `requests`; access to the named endpoints. The current ChEMBL release can change; the validation script intentionally checks this snapshot. The 594,284,548-byte BindingDB archive is a downloadable input, not a deliverable. Patent/figure values are explicit source transcriptions embedded in the build script, not automatic extraction or model predictions. ChEMBL data are attributed to ChEMBL/EMBL-EBI and available under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

## Database sources

- ChEMBL exact target: [CHEMBL3820 metadata](https://www.ebi.ac.uk/chembl/api/data/target/CHEMBL3820.json) confirms human P35557. [All activities, first page](https://www.ebi.ac.uk/chembl/api/data/activity.json?target_chembl_id=CHEMBL3820&limit=1000&order_by=activity_id); follow `page_meta.next` and join `/document/{document_chembl_id}.json` (103 documents) for DOI, title and PMID. Source compound keys/names were independently retrieved from `/compound_record/{record_id}.json`; e.g. [3](https://www.ebi.ac.uk/chembl/api/data/compound_record/2481282.json), [11](https://www.ebi.ac.uk/chembl/api/data/compound_record/2481290.json), and [8](https://www.ebi.ac.uk/chembl/api/data/compound_record/2481287.json). The exact dump returned **3,222 activity records**. Primary potency fields: 1,378 EC50 (1,360 numeric), 99 IC50, 29 Kd, zero AC50/SC1.5/Ki standard types. Genuine ligand-binding rate/time values: **72** (34 baseline K rates, 17 baseline T1/2, 14 stopped-flow K rates, 7 stopped-flow TIME). The generic kon and k_off labels were **12 null-valued** kinase-screen entries, not human GCK activator rates. Descriptions, units and assay IDs were screened, not only endpoint names. Baseline assays `CHEMBL3582523`, `CHEMBL3583538`–`CHEMBL3583541`; stopped-flow assays `CHEMBL4428660`–`CHEMBL4428668`.
- BindingDB: [UniProt P35557 affinity REST](https://www.bindingdb.org/rest/getLigandsByUniprots?uniprot=P35557&cutoff=1000000) returned 1,456 rows but **does not expose rate fields**. [November full TSV archive](https://www.bindingdb.org/rwd/bind/downloads/BindingDB_All_202611_tsv.zip), exact `P35557` in any UniProt SwissProt primary target-chain column: **1,484** human Hexokinase-4 rows, **0 kon and 0 koff**. Populated affinities: 1,346 EC50, 98 IC50, 12 Kd. No inference of absence was made from the REST result alone.

## Literature and figures

- Search endpoints and copyable query strings are in [search_literature.py](scripts/search_literature.py); run `python search_literature.py` from `gck-kinetics/scripts` to regenerate `data/search_results.json` with resolved URLs and result metadata. Search is not needed to rebuild the CSVs. The PubMed title/abstract screen found 6 papers (29626326, 27391254, 24717911, 19459610, 18809676, 16768451). The broad Europe PMC full-text SPR/sensorgram query returned 660 hits, many unrelated; the activator/kinetics query returned 155. The targeted title/abstract plus full-text terms query returned 12 with bare `SPR` included, or 11 without it. Search hits are discovery leads, not a systematic review of every document.
- Clinical/series search (grouped aliases, same Europe PMC keyword filter): piragliatin/RO4389620 1, dorzagliatin/HMS5552 4, AZD1656/AZD6370 2, MK-0941 3, PF-04937319/PF-04991532 1, GKA50 2, LY2608204 0, TTP399 0, AMG-151/ARRY-403 5, GKM-001 0, ZYGK1 0. The apparent dorzagliatin residence-time hits were pharmacokinetics; no qualifying additional rates were verified from these searches. AZD1656 and MK-0941 are already in Borzilleri, and piragliatin also appears in Mollica.
- **Borzilleri et al.** [10.1039/C4MD00027G](https://doi.org/10.1039/C4MD00027G): official article and author manuscript returned 403 and OpenAlex marked it closed, but the [archived RSC SI PDF](https://web.archive.org/web/20240606102951id_/https://www.rsc.org/suppdata/md/c4/c4md00027g/c4md00027g1.pdf) was accessible. Fig. S1 has sensorgrams *and numeric rates* for compounds 6 and 15, and Table S1 confirms human off-rates for 6, 7 and 15. These agree with ChEMBL. Fig. S2 and the methods give the 22-by-16 concentration matrix, EC50 definition and complete 50 mM glucose SPR conditions. Individual Table 1 values were recovered from ChEMBL where not repeated in SI; no figure digitization. Pair by `record_id`, not ChEMBL molecule ID: compounds 3 and 11 are oppositely rotating enantiomers sharing one non-stereo entry. Compound 8 is the isolated negative enantiomer of the compound-6 scaffold per SI pp. 9–10; registry ID CHEMBL499520 gives an unrelated structure, so the output uses supported canonical connectivity only and omits that ID. Neither optical rotation sign nor elution order establishes R/S here.
- **Mollica et al.** [10.1021/acs.jmedchem.6b00632](https://doi.org/10.1021/acs.jmedchem.6b00632): full text was not accessible from the publisher or institutional metadata pages [Bologna](https://cris.unibo.it/handle/11585/586990) and [Birmingham](https://research.birmingham.ac.uk/en/publications/8fcfb831-7095-4dba-b9a9-4fcd08217d90). The [ACS SI lookup](https://api.figshare.com/v2/articles?resource_doi=10.1021/acs.jmedchem.6b00632) yielded [PDF](https://ndownloader.figshare.com/files/5524994) and [CSV](https://ndownloader.figshare.com/files/5524997). CSV supplies compound identities, structures and Kd; SI PDF S5/S6 establishes mixture scope and source names (prefer its naming and ChEMBL source records where SI CSV labels for the individual enantiomer structures conflict). Kinetic values come from the ChEMBL curation, not the simulated unbinding trajectories in SI. The exact glucose concentration, buffer and temperature for the competition measurements could not be verified, and were not filled from a different paper. Mollica measured seven samples; two overlap Borzilleri (piragliatin and TAFMT, by structures).
- **Antoine et al.** [10.1021/bi900374c](https://doi.org/10.1021/bi900374c): publisher blocked, [author-institution copy preserved by Internet Archive](https://web.archive.org/web/20170811220322id_/http://depa.fquim.unam.mx/proteinas/mdcb/press/pp1.pdf) accessible. Fig. 3/materials identify fluorescent compound A as TAFMT and LY2121260 as Mollica compound 3. Fig. 5/caption provides approximate room-temperature equilibrium affinity; text reports numeric association and displacement dissociation rates associated with Figs. 6–9 at 25 °C and 100 mM glucose with and without 4 mM AMP-PNP. These independent conditions add observations, not another compound. Apo-GCK conformational fits/rough microscopic estimates were not pooled with the robust observed binary-complex rates. No points were digitized.
- [10.1021/ml400061x SI](https://ndownloader.figshare.com/files/4036588): while the setup uses stopped flow, the time constant is a catalytic progress-curve lag (change in coupled absorbance at 340 nm), **not** the drug off-rate. ITC measures equilibrium Kd only. [10.1016/j.bbagen.2018.06.001](https://www.ncbi.nlm.nih.gov/research/bionlp/RESTful/pmcoa.cgi/BioC_xml/PMC6051901/unicode) Fig. 9 measures the rate of **glucose** binding; the [Whittington study](https://www.ncbi.nlm.nih.gov/research/bionlp/RESTful/pmcoa.cgi/BioC_xml/PMC3023980/unicode) likewise studies glucose. The initial Europe PMC `/{PMCID}/fullTextXML` tests (PMC6051901, PMC3840467, PMC3340189, PMC3791601, PMC10659937, PMC4305461, PMC6377845) returned 500; we used accessible BioC retrieval and Figshare SI as fallbacks. Other full texts neither offered nor retrievable were not represented as absences of rates.
- [10.1021/acs.jmedchem.5b01367 SI](https://ndownloader.figshare.com/files/3574665), Table S6: SPR for GKRP is not SPR for GCK; ChEMBL additionally lists human GCK SPR Kd for compounds 6 and 12, but no human GCK rates were verified for these GKRP disrupters.

## Patents

[Google Patents service](https://patents.google.com/xhr/query) inputs are in the script. The first search pass including “surface plasmon resonance” returned 11 results; “dissociation rate” 6, “residence time” 74, “koff” 1, and broad “glucokinase activator” 5,044. A later scripted rerun received HTTP 503 from the search service; that status is preserved in the search metadata. Priority hits read using `https://patents.google.com/patent/{publication}/en`: [TWI418558B](https://patents.google.com/patent/TWI418558B/en) reports isomer chromatographic retention times plus activation EC50, not ligand-target residence time; TWI580678B and TWI410423B also use chromatography “residence time”; WO2020086388A1 mentions SPR as a general detection method; JP2022095624A uses kon/koff for antibody–antigen binding, not GCK. US10980861B2 and JP5419706B2 gave no additional binding kinetics in this screen. [US8492405B2](https://patents.google.com/patent/US8492405B2/en) Experimental Example 1 Table 1 gives five human liver GCK EC50 values (5 mM final glucose) but no binding rates. Those five examples are indexed by patent/example, without an independently normalized structure. BindingDB supplies additional patent potency labels with SMILES. This was a targeted Google Patents screen, not exhaustive family/claim enumeration across Espacenet or SureChEMBL.

**What blocks a bigger join:** the full BindingDB P35557 extract has no rate values; all qualifying ChEMBL rate rows come from the two known studies above; patents and most medicinal chemistry assays provide functional activity or equilibrium affinity only. The usable figure-source paper adds independent states to two already identified compounds, not new identities. Unverified full texts, unreported stopped-flow conditions, unresolved absolute stereochemistry and racemate-level measurements limit how much can become a comparable compound-level training dataset. Under an SPR-only restriction the verified expansion is zero.
